# Задание для Claude Code: установить проект на Windows

Ты работаешь на компьютере будущей пользовательницы программы. Помоги установить этот репозиторий и получить один проверенный разбор тестовой записи. Общайся по-русски, простыми словами. Прежде чем устанавливать зависимости, создавать папки или менять настройки, выполни пункты 1 и 2.

## 1. Сначала диагностика — ничего не менять

Проверь доступными средствами и сразу сообщи короткий список **«Уже есть / Не хватает / Не удалось проверить»**:

- Версия и архитектура Windows, доступное место на дисках.
- Python: `py --list-paths`, `py -3.12 --version` либо другой установленный совместимый Python 3.11+. Проверяй реальный интерпретатор, а не только псевдоним Microsoft Store.
- Git (если репозиторий ещё нужно клонировать; скачанный ZIP не требует Git).
- FFmpeg и ffprobe: наличие в PATH и вывод версии.
- Claude Code CLI: расположение `claude`, версия, возможность работы в выбранном терминале. Проверь авторизацию доступной командой состояния, не делай платный тестовый запрос без перехода к согласованной проверке.
- Нужные Python-пакеты в выбранном окружении, если оно уже существует.
- Наличие совместимых ONNX-моделей, если пользовательница уже скачивала их.
- Ограничения сети/прокси и права записи в выбранные каталоги проверяй по фактам. Непроверенное не называй отсутствующим.

Не читай содержимое личных папок и переписку ради диагностики. Не выводи токены, API-ключи и содержимое файлов авторизации. Если чего-то нет, назови компонент, зачем он нужен и точное следующее действие. Не проси «дать доступ» без конкретного препятствия.

## 2. Спроси о папках и способе работы

До создания папок спроси одним понятным сообщением:

1. На каком диске и в какой папке разместить саму программу?
2. Где хранить записи и результаты разбора? Уточни, что там будут подпапка `Входящие`, папки по датам, исходные видео, расшифровки и задачи. Объясни, что файл из `Входящие` перемещается в папку встречи. Если нужен неприкосновенный оригинал, предложи копировать его во `Входящие`.
3. Где хранить модели распознавания? Они могут находиться отдельно от записей и программы.
4. Нужны ли уведомления Telegram или достаточно файлов и вывода в окно? Нужен ли периодический запуск или пока запускать вручную?

Предложи примеры путей, но **не выбирай их за пользовательницу и не создавай до ответа**. Учитывай пробелы и кириллицу в путях. Не предполагай наличие диска D:. Не размещай приватные записи в публичном репозитории. Проверь свободное место и права в выбранном месте.

## 3. Согласуй и выполни установку

Объясни, что будет установлено, какие папки будут созданы, что отправляется внешним сервисам: аудио распознаётся локально, но полный текст расшифровки отправляется Claude, а уведомления при включении Telegram — Telegram. Убедись, что пользовательница согласна с таким использованием её записей.

Используй актуальные официальные инструкции издателей для установки Python, Claude Code CLI и FFmpeg. Не запускай случайные установочные скрипты из сторонних источников, не отключай антивирус или системные ограничения. Системные изменения и повышение прав согласовывай отдельно, если они действительно нужны. По возможности устанавливай для текущего пользователя.

- Клонируй этот репозиторий либо используй уже скачанную копию.
- Создай `.venv` выбранным Python и установи `requirements.txt`.
- Веса: проверь актуальные официальные инструкции GigaAM и sherpa-onnx; найди совместимый ONNX transducer, а не произвольный файл с похожим названием. Не утверждай, что модель готова, пока не проверены файлы и реальная загрузка Recognizer. Если подходящие веса недоступны, прямо сообщи, что именно блокирует ASR.
- Авторизацию Claude выполняет сама пользовательница. Не проси присылать пароль или токен в чат.
- Задай `CALLS_RECORDS` и `CALLS_MODELS` выбранными абсолютными путями.
- Создай локальный `run-calls.ps1` с абсолютным путём к Python из `.venv`, установкой переменных и запуском `calls.py run` из каталога проекта. Сохраняй приватный скрипт вне отслеживаемых файлов или исключи его через `.git/info/exclude`.
- Не меняй глобальную ExecutionPolicy. Если запуск .ps1 ограничен политикой, используй согласованный локальный .cmd с теми же переменными и кавычками либо ручные команды, совместимые с действующей политикой.
- Telegram настраивай только по желанию. Секреты храни локально, не в отслеживаемом скрипте и не в репозитории. Перед тестовой отправкой уточни выбранного получателя; покажи результат с message_id без токена.
- Программа не записывает созвоны. Если записывающей программы нет, сообщи об этом; сначала можно взять готовый короткий файл. Настройка записи экрана — отдельный согласованный шаг.
- Не включай календарь и не подключай посторонние аккаунты. Задачи сохраняются в `tasks.json`.

## 4. Проверь результат

1. Запусти `preflight.py` через Python из созданного окружения. Покажи каждый отсутствующий компонент и исправь согласованные проблемы.
2. Запусти `python -m unittest discover -s tests -v` тем же интерпретатором.
3. С разрешения пользовательницы возьми короткую НЕконфиденциальную русскую тестовую запись. Для проверки разбора в ней должно быть больше 40 слов. До запроса Claude напомни, что текст уйдёт внешнему сервису и запрос расходует доступный лимит.
4. Скопируй тестовый файл во `Входящие` выбранной папки и запусти `run-calls.ps1` или эквивалентную команду.
5. Проверь наличие и содержимое `расшифровка.txt`, `разбор.md`, `tasks.json`, `.конвейер.json`. Убедись, что речь распознана осмысленно, задачи относятся к нужному человеку, а повторный запуск не делает новый разбор той же записи.
6. Если заказан автоматический запуск: создай задачу в Планировщике от текущего пользователя с полными путями и рабочим каталогом, согласованным интервалом (например, 30 минут). Учитывай пользовательские переменные и авторизацию CLI. Проверь ручной старт задачи; не называй расписание проверенным до фактического автоматического запуска. Не обещай обработку при выключенном компьютере.

Если Windows-ветка, CLI или модели дают ошибку — приведи точную ошибку без секретов, исправь по факту и повтори проверку. Не выдавай Linux-тесты автора за проверку Windows.

## 5. Передача пользовательнице

Дай короткую памятку с **её реальными выбранными путями**:

- куда класть новые записи;
- где искать результат;
- как запустить обработку;
- включён ли автоматический запуск и когда он реально проверен;
- какие данные уходят Claude/Telegram;
- что осталось недоступным или непроверенным.

Не заканчивай словами «всё готово», если не прошёл реальный тест на этом компьютере. При блокере оставь рабочую независимую часть (например, расшифровку без Claude) и объясни ровно одно необходимое следующее действие.
