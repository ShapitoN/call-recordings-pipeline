# Call Recordings Pipeline

Локальная расшифровка русскоязычных записей созвонов через GigaAM v3 / sherpa-onnx и краткий разбор через Claude Code CLI. Поддерживает Windows и Linux на уровне кода; проверка этой публичной сборки выполнена на Linux с синтетической записью и подменёнными ASR/Claude. Реальный запуск на Windows требует проверки при установке.

**Установка под Windows с помощью Claude:** откройте [INSTALL_FOR_CLAUDE.md](INSTALL_FOR_CLAUDE.md) и передайте содержимое Claude Code на компьютере, где будет работать программа. Он должен сначала проверить систему и спросить, куда устанавливать проект и где хранить записи и модели.

## Что делает

1. Забирает аудио/видео из `Входящие` внутри выбранной папки записей.
2. Раскладывает по `ДД.ММ.ГГГГ/ЧЧ-ММ`, сохраняет исходник как `запись.*`.
3. Создаёт `расшифровка.txt` с минутами и, при отдельных аудиодорожках, метками «Я» / «Собеседник».
4. Одним запросом Claude создаёт `разбор.md`: суть, задачи, обещания, условия и важные цитаты.
5. Экспортирует собственные задачи и проверки работы разработчиков в `tasks.json` рядом с разбором.
6. Опционально отправляет итог через Telegram Bot API. Без Telegram пишет уведомление в консоль.

Приложение само не записывает экран и не подключается к созвонам. Ролики нужно записать другим приложением и положить во входящую папку. При импорте исходник **перемещается** из `Входящие`, а не копируется. Автоматического запуска по таймеру в поставке нет: сначала настройте ручной запуск, затем при необходимости Планировщик заданий Windows.

## Требования

- Python 3.11+; рекомендуемая исходная точка — Python 3.12 x64.
- FFmpeg и ffprobe в PATH.
- Claude Code CLI (`claude`), авторизованный пользователем; доступ к модели Sonnet.
- Python-пакеты из `requirements.txt`.
- ONNX-модели ниже. Веса не входят в репозиторий. Совместимость и лицензии весов проверяйте у их издателя.

Структура выбранной папки моделей:

```text
models/
  silero_vad.onnx
  giga-am-v3/
    encoder.int8.onnx
    decoder.onnx
    joiner.onnx
    tokens.txt
```

Ожидается GigaAM v3 в формате transducer для sherpa-onnx (`nemo_transducer`). Произвольный PyTorch checkpoint или ONNX от другой версии не подойдёт. Источники для поиска совместимых весов: [GigaAM](https://github.com/salute-developers/GigaAM) и [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx). Проверяйте актуальные инструкции издателя при установке.

## Ручной запуск (PowerShell)

Из папки проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:CALLS_RECORDS = 'D:\Calls\Recordings'
$env:CALLS_MODELS = 'D:\Calls\Models'
.\.venv\Scripts\python.exe preflight.py
.\.venv\Scripts\python.exe calls.py status
.\.venv\Scripts\python.exe calls.py run
```

Пути выше — примеры, выберите свои. Переменные PowerShell действуют только в текущем окне. Для постоянной настройки используйте локальный скрипт запуска, создаваемый по инструкции установки. `.env.example` — справочник переменных; программа сама `.env` не читает.

Linux: создайте venv через `python3 -m venv .venv`, установите зависимости, задайте те же переменные среды и используйте `.venv/bin/python`.

Только расшифровка: `python calls.py transcribe input.webm output.txt`. На этом шаге Claude не вызывается.

## Приватность и ограничения

- ASR выполняется локально. **Для разбора полный текст расшифровки и исходное имя файла отправляются Claude**, а при включённом Telegram краткий итог уходит Telegram. До использования с частными разговорами учитывайте это и получите необходимые согласия участников.
- В репозитории нет записей, личных расшифровок, токенов, моделей, рабочих логов или истории исходного проекта.
- Telegram: задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` только локально. Отправка прямая, без внешней очереди доставки. Ошибка уведомления может потребовать ручного повтора; `notified` без `telegram_id` не доказывает доставку в Telegram.
- Папка `logs` содержит метаданные встреч, расход токенов и иногда некорректные ответы Claude; она исключена из Git. Записи и модели по умолчанию также исключены. Не добавляйте свои данные принудительно через `git add -f`.
- `CALLS_EXTERNAL_SUMMARIES` — необязательный каталог итогов другого помощника в формате `YYYY-MM-DD_HH-MM-SS…— итоги.md`; при совпадении времени подавляет дубли уведомлений.
- Календарь отключён константой `CALENDAR_ENABLED = False`. Оставшийся код старой интеграции не настроен и не входит в поддерживаемую установку.
- Поддерживается русская речь; несколько собеседников в одной дорожке не различаются. Имена, суммы и обязательства требуют проверки человеком.
- Повтор разбора после ошибки: до шести попыток с растущими интервалами, но каждая попытка требует нового запуска `run` (вручную или таймером).
- Ошибка ASR сохраняется в `.конвейер.json` и сама не повторяется. Исправьте причину, сделайте резервную копию состояния и удалите только `transcribe_error` для повторного запуска.
- Полный клиентский пакет (КП, схемы, Obsidian, Drive) и личная панель задач в эту самостоятельную версию не входят.

## Проверки

```text
python -m unittest discover -s tests -v
python preflight.py
```

Тесты не загружают модели, не отправляют сообщения и не вызывают платную модель. Предпроверка только читает настройки и проверяет доступность компонентов, ничего не устанавливает и не создаёт.
